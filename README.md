⚙️ Installation

Clone the repository:

git clone https://github.com/vaibhav-surase/my-chatbot-app.git

Navigate to the project folder:

cd my-chatbot-app

Install dependencies:
npm install
Start the application:
npm start
Application will run on:
http://localhost:3000
🐳 Run with Docker
Build Docker image:
docker build -t my-chatbot-app .
Run container:
docker run -p 3000:3000 my-chatbot-app
